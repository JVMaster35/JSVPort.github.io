About This Project

This project involved the development of a vertical SHMUP game in Unity Engine using C#. Implemented component-based architecture, shooting systems, curved movement via node paths, scene transitions, save/load systems, Scriptable Objects, collectible systems, and achievement tracking.

Game assets were provided by the course. All gameplay systems and scripting were written by me under instruction from Romi Fauzi.
