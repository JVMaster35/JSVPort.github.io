About the Project

As a part-time programmer for Armada Studios, I contributed to the development of a modern fan sequel to Sega’s 1995 game Tails Adventure, titled Tails Adventure Armada.

Staying true to the original, the project is a 3D platformer featuring gadget-based traversal, combat systems, and free-roaming exploration. Players utilise various tools to overcome obstacles, defeat enemies, and access new areas, while leveraging Tails’ signature flying ability for vertical traversal and strategic movement.

My responsibilities included implementing gameplay systems in C#, including:

  • Player movement and jumping mechanics
  • Flight system implementation
  • Animation synchronisation
  • Enemy detection and combat interactions

The project remains in active development, and I continue contributing to its core gameplay systems.
