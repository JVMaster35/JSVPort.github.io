About the Project

Developed during my third year in the Games Technique course, this project was inspired by the multiplayer stunt game Crash Drive 2. Players can select vehicles and perform tasks to earn points.

I created two levels for the game: a desert landscape and an arctic region. I implemented network connections to allow multiple players to join servers. Additionally, I developed a garage for vehicle selection and a lobby system for joining or hosting games.

While gameplay and end screens were not fully implemented, the project demonstrates multiplayer connectivity, cross-network functionality, and server scalability.
