About Me

A games programmer with seven years of production software experience behind him.

I studied Computer Games Development at the University of Northampton, graduating with a 2:1. Since 2019 I've worked as a Software Developer & DevOps engineer at a data-management consultancy serving financial-market clients, building and maintaining Java web applications hosted on AWS.

That job is where I learned to work on large, long-lived codebases: tracking down concurrency bugs and database connection leaks, removing performance bottlenecks, cutting AWS CloudWatch monitoring costs, setting up Cloudflare bot monitoring, writing SQL reporting and helping rebuild a legacy JSP platform in Spring Boot and React. The same habits — profile it, understand it, fix the root cause — carry straight into game code.

Outside work I make games: gameplay programming on the fan project Tails Adventure Armada, solo and small-team game jams, and structured courses in Unity and Unreal Engine 5. I'm drawn to story-driven games with rich worlds, and away from the keyboard I'm usually drawing, writing stories or playing chess.

I'm looking for a junior gameplay or systems programmer role where I can bring that engineering discipline to a games team.
