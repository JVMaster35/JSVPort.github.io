About the Project

For our third-year group project, I worked with four other developers and artists to create a 3D multiplayer game for PC and console. We designed "Toybreakers", a fun, vehicle-based battle-royale game with toy-inspired characters.

The game supports up to four players, AI or human, competing in various modes:

  • Kill Count: Players aim for the highest number of eliminations.
  • Time Limit: Score the most kills within a set time.
  • Life Count: Reduce opponents' lives to zero.
  • Chaos Mode: Randomized power-ups add unpredictability.

My contributions included implementing game logic in C#, integrating 3D models and UI elements, and creating: the game loading system, power-up mechanics, game settings (time, lives, players), victory screen, and the character selection interface.
